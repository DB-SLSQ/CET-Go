============================================================
  CET Go  ·  看释义 · 拼单词
  （对标日本「漢字でGO!」，把「看汉字→打读音」换成「看释义→拼单词」）
============================================================

【怎么打开】
  双击桌面上的「CET Go」图标。
  或者双击：  D:\CetGo\CET Go.vbs

  · 不会再出现任何黑框 / cmd 窗口。
  · 打开的是一个独立的应用窗口（没有地址栏、没有标签页），
    看起来就是一个正常的桌面软件。

【第一次打开有点慢？】
  第一次要先启动本地服务 + 载入约 5800 个单词，大约 2~3 秒。
  之后就是秒开。

【怎么关闭】
  直接点窗口右上角的 × 即可。
  窗口关掉后，后台服务会在 150 秒内自动退出，不用管它。
  想立刻停掉后台服务：双击「Stop CET Go.vbs」，或者在
  游戏里的「设置 → 退出应用」。

============================================================
  玩 法
============================================================
  屏幕中央出「中文释义」，词卡会从远到近朝你压过来 ——
  时间条走完就是撞到你脸上，所以趁它远远的时候把单词打出来。

  开局先选两样东西：

  难度
    · 普通    15 秒 · 3 条命 · 提示 3 次
    · 困难    10 秒 · 3 条命 · 提示 2 次 · 偏长词
    · 极难     7 秒 · 2 条命 · 提示 1 次 · 长词
    · 地狱     5 秒 · 1 条命 · 没有提示，而且只出长单词

  题量
    · 7 题 / 10 题 / 16 题

  选完点「準備 OK!」开始。

  题面会直接告诉你这个单词有几个字母（词性右边那个粉色数字，
  比如「9 字母」）—— 不用去数下面那排下划线槽。
  下面那排槽是「提示」，答案揭晓（答对/超时）时会自动收起。

  判定：大小写、空格、连字符都无所谓，拼对了就算对。
  答对 → 印章「正解！」+ 加分 + 连击；
  打错 → 红闪 + 震屏 + 断连击，但**不扣命**：时间没走完就能
        无限次重试，输入框会自动清空，接着打就行；
  超时 → 印章「TIME UP」，卡片会先贴到脸上再退回来，
        这才算答错 —— 扣一条命，词进错题本。
  答对和超时都会当场显示「正确答案 + 音标 + 完整释义」；
  打错（时间没走完）不显示答案，不然就没得猜了。

  结算页会列出这一局所有拼错的词，可以一键重练。
  错过的词也会自动进「错题本」，随时翻出来复习。

  词表在「设置」里切换：CET4(3518) / CET6(2271) / 全部。
  进度跟英语六级备考那个应用是分开的，互不影响。

============================================================
  局域网模式（/lan）怎么开
============================================================
  服务默认只在本机（127.0.0.1），外面连不进来。
  要让同一 Wi-Fi 下的另一台电脑下载电脑版，得绑到局域网：

    tools\console-lan.bat    双击即可，会弹一个小黑窗打印
                             局域网地址和 /pc 下载直链。
                             这个窗口开着的时候外面才连得上，
                             用完关掉就行。

  也可以给「CET Go.vbs」加一个 /lan 参数启动：
    右键桌面「CET Go」→ 属性 → 「目标」末尾加上  /lan
    （注意空格）→ 确定。

  ⚠ 开了局域网之后，同一个 Wi-Fi 下的设备都能读写你电脑上的
    记录。用完记得关掉（关掉窗口，150 秒后服务自动退出）。

============================================================
  给别人一份电脑版（绿色免安装包）
============================================================
  同学想要一份？不用教他装 Node.js —— 直接把这个包发过去：

    dist\CETGo-PC.zip        35.5 MB   自带 node.exe，解压就能玩
    dist\CETGo-PC-lite.zip    4.0 MB   不带 node.exe，对方得先装 Node

  两个包里面的东西一模一样，双击「CET Go.vbs」启动。
  完整版里那个 node.exe 会被启动器优先使用，所以对方电脑上
  没装 Node 也照样跑 —— 这一点是实测过的（起服务后查过
  进程的可执行文件路径，确实是包内那个）。

  对方拿到之后：
    1. 解压（右键 → 全部解压缩）
    2. 双击「CET Go.vbs」
    3. 第一次会问「是否允许」，允许即可
  万一对方的电脑把 .vbs 拦了（安全软件 / 组织策略），
  就改双击「CET Go.bat」—— 功能一样，只是会多一个黑窗口。

  包发的渠道：
    · 另一台电脑连同一个 Wi-Fi 的话，让它在浏览器打开
      http://<电脑的局域网地址>:27656/pc  直接下（前提是 --lan 启动）
    · QQ / 微信 直接传文件（35 MB 没问题）
    · 邮件发不了这个 35 MB 的（Agent Mail 单附件上限 20 MB），
      精简版 4 MB 可以，但对方得自己装 Node

  重新打包：
    python tools\build-pc-zip.py            # 完整版 + 精简版
    python tools\build-pc-zip.py --full     # 只要完整版
    python tools\build-pc-zip.py --lite     # 只要精简版

  包里有意识地**没**放：调试页（_*.html）、tools\、docs\、
  你自己的存档（data\state.json）。

============================================================
  文件都是干什么的（一般不用管）
============================================================
  CET Go.vbs           启动器 —— 双击这个（没有黑框）
  CET Go.bat           同上，备胎（.vbs 被安全策略拦时用）
  Stop CET Go.vbs      停掉后台服务（静默）
  server.js            本地服务，端口 27656
  public\              界面和游戏逻辑
  data\                词库 + 你的记录（state.json）
  app.ico              图标
  dist\CETGo-PC.zip    电脑版绿色包（发给同学 / 另一台电脑）
  tools\build-pc-zip.py    重新打包电脑版绿色包
  tools\console-lan.bat    要开局域网模式的时候双击它
  tools\console-start.bat  排错用：会显示控制台和报错
  tools\console-stop.bat   排错用：命令行停服务

  · 完全离线，不联网、不上传任何数据。
  · 记录只存在本机 data\state.json 里。
  · 想彻底重置：删掉 data\state.json 即可。

============================================================
  打不开怎么办
============================================================
  1. 双击 tools\console-start.bat，看屏幕上打印的报错。
  2. 常见原因：Node.js 被卸载 / 挪走了。
     装回 https://nodejs.org ，或把 node.exe 放到 D:\nodejs\。
  3. 端口 27656 被占用：重启一下电脑，或问一下我。
